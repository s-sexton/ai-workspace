# Financial Statements To Shareholders

This note documents the learned status for AM-017.

Do not store financial statement contents, shareholder private details, email
addresses, raw report exports, credentials, or sensitive company financial data
in this file.

## Current Status

- Active monthly task.
- Target timing is Day 7.
- The task often gets pushed back today; the process should become firmer about
  the target date.

## Report Package

Typical reports include:

- Profit and Loss.
- Balance Sheet.
- Any additional reports requested for that month.

## Sources

Reports are mostly generated from QBDT. A spreadsheet may also be involved.
Automation is desired if it can be done safely and reliably.

## Storage

The final package should be stored in the monthly `YYYYMM` folder.

## Delivery

Current delivery is usually by email. A better delivery method should be
evaluated, with attention to access control, confidentiality, and confirmation
that delivery happened.

## Completion Check

AM-017 is complete when the reports have been delivered and questions have been
answered.

## Streamlining Notes

- Evaluate whether report generation can be automated from QBDT and supporting
  schedules.
- Define a cleaner delivery method than ad hoc email.
- Add reminder escalation if the Day 7 target is at risk.
